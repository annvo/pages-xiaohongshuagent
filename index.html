方法与原则

证据门槛、来源优先级、空态诚实与行动拆分。

证据门槛

高风险结论需要更高证据密度：原始文件或权威报道、多源交叉、明确时间与主体对齐。达不到门槛就标为待核验或丢弃。

来源优先级

原始通告 > 主流报道 > 研究机构 > 行业媒体 > 聚合转载。越靠后，越需要额外核验。

对立解释

同一事件若存在多方说法，摘要并列呈现，不把“更响的声音”写成唯一事实。

降级规则

缺链接、缺时间、主体不清、明显营销话术：不进入确定性表述，最多作为线索。

空态诚实

今日无足够可信材料时显示空态。空态是质量信号，不是系统故障。

更新失败

日更任务失败时，页面保持可访问；新闻区显示空态或上次可信状态，不用低质量条目填满。

摘要边界

摘要服务扫描，不服务情绪。不扩写未证实动机，不预测未发生结果。

行动拆分

证据优先

对称优先

空态优先

人工负责

深度说明

为什么这样编排，以及如何把本页用于预研而不是替代尽调。

xiaohongshuagent.com 选择把声明、方法、风险纪律与新闻编排放在同一视图，是为了减少“多级页面导致声明漂移”的问题：访客不需要点进二级页才能看到“非官网、无授权、非客服”。对「小红书」名称的使用，始终服务于指称与检索，而不是视觉或话术上的官方化。

在 内容社区 中阅读公开信息，常见误判有三类：把标题情绪当事实、把转载当一手来源、把未证实渠道消息写进决策备忘。本站的纠偏顺序是：先主体、后时间、再对立解释、最后才行动。检索词「小红书 / Xiaohongshu」只负责发现候选，不负责证明相关。

风险栏目标展示量约为进展栏的三倍，不是为了制造负面，而是对冲传播结构：建设性通稿与合作稿通常更容易被放大。配额是展示纪律；当没有足够可信材料时，风险栏同样可以空态。空态比硬凑更有利于信任。

日更识别设定在北京时间 00:00，对应可预期的节奏。节奏服务的是漏读控制，而不是“每天必须有猛料”。任务失败时，正确做法是保留上次可信状态或显示空态，而不是用低质量填充换取“看起来很忙”。

若你把本页用于 Agent / MCP 相关工作，请把自动化当作加速器而不是责任转移：可交付物应可审计（依据是什么、不确定在哪里、影响范围、下一步是什么）。支付、删除、群发等不可逆动作必须门禁；密钥与生产数据默认不进演示环境。域名命名与落地页不能替代安全设计。

行业专属阅读框架（内容社区）：内容社区观察应覆盖创作者生态、商业化、算法分发、虚假信息与未成年人保护。 建议按结构轴「创作者工具与激励 / 商业化 / 推荐分发 / 治理与举报 / 隐私」组织材料，而不是按标题刺激度排序。
